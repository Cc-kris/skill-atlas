# Skill Atlas MVP PRD

版本：v1.0 | 日期：2026-09-16 | 状态：已实现

## 需求

- REQ-001 Must：自动识别或显式选择 Codex、Claude Code、WorkBuddy、OpenCode、Generic 宿主，并只扫描该宿主白名单根目录。
- REQ-002 Must：读取 `SKILL.md` 与可选 `skill.json`，输出统一 SkillRecord；缺失或损坏元数据降级并保留 warning。
- REQ-003 Must：依据当前名称、描述、触发词和标题动态分类，超过 10 个时递归拆分，最多三级。
- REQ-004 Must：生成内嵌 JSON、CSS、JavaScript 的离线单文件 HTML 和 sibling JSON 快照。
- REQ-005 Must：页面支持搜索、状态/层级筛选、分类展开折叠、节点详情、拖拽平移、滚轮缩放、重置和移动端详情抽屉。
- REQ-006 Must：不执行 skill 脚本、不读取凭据目录、不输出完整敏感路径，单个异常不阻断全量扫描。
- REQ-007 Must：同一输入的记录、分类和节点顺序稳定。

## 非目标

不安装/修改/删除 skill，不联网，不使用常驻服务或外部模型。
