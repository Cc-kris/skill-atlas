# Skill Atlas MVP 技术方案

版本：v1.0 | 日期：2026-09-16 | 状态：已实现

## 架构

`build_atlas.py` 编排 `host_adapters.py`、`scanner.py`、`metadata.py`、`classifier.py` 和 `build_html.py`。adapter 只解析宿主根目录；脚本只读取允许的 metadata 文件；HTML 模板无 CDN 和外链。

## 字段契约

| 字段 | REQ | 来源 | 类型 | 空值策略 | 消费位置 | 生成位置 |
|---|---|---|---|---|---|---|
| `host` | REQ-001 | adapter | string | 未识别则 CLI 失败 | HTML header | host_adapters |
| `skills[].name/description/triggers` | REQ-002/003 | SKILL.md/skill.json | string/list | 目录名、空列表降级 | 搜索、详情、分类 | metadata/scanner |
| `skills[].category/level` | REQ-003 | 本地分类器 | string/int | `Other`, level 1 | SVG、筛选 | classifier |
| `skills[].status/warnings` | REQ-002/006 | 解析过程 | enum/list | valid/空列表 | 统计、详情 | metadata |
| `skills[].path` | REQ-006 | root + relative | string | 相对文件名 | 详情 | metadata |

完整 JSON Schema 见 `skill-atlas/references/output-schema.json`。

## 兼容、安全、回滚

新增模块不改变宿主原文件；`--host` 保留显式兼容入口，`--root` 支持 Generic。失败只产生 CLI 错误或 warning，不写入扫描根目录；输出文件可直接删除重建。排除 auth/credentials/history/cache/backup 等目录，不执行脚本，不调用网络。
